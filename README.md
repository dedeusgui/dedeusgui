Sou desenvolvedor full stack com foco em backend. Trabalho com Java/Spring Boot, C#/.NET e Python no back-end, e com React/TypeScript e Kotlin no front-end e nos apps Android. Tenho sistemas em produção, incluindo automação de processos e integrações com APIs de terceiros.

Estou aberto a oportunidades remotas em todo o Brasil. Sou de Cachoeirinha/RS, com português nativo e inglês avançado (C1).

Se for avaliar código, comece pelo [PICK](https://github.com/dedeusgui/PICK), que tem React, Express, Docker e testes E2E. Para o contexto profissional, veja a experiência abaixo e fale comigo pelo contato no final.

## 🧠 Como eu trabalho

- Levanto as necessidades com as áreas envolvidas, desenho a solução e registro as decisões em ADRs.
- Escrevo a especificação e os testes antes da implementação (SDD + TDD).
- Uso Claude Code e Codex com `AGENTS.md`, skills e contexto de projeto, em worktrees isoladas, rodando só os testes dos módulos afetados.
- Mantenho CI/CD no GitHub Actions, com quality gate, revisão de código por agentes e checagem de drift da documentação.
- Faço commits semânticos.
